SIREN鳴物

The percussion of the set

キックは、丸ではない。面が受けた打撃の跡だ。SIREN（鳴物）は、16ステップのリズムで"面"に痕を刻むサンプラー型のプラグイン。5つのボイス（kick / snare / hat / bass / rim）が同じ面への操作——殴り、裂き、割り、持ち上げ、削る。生まれるのは、ぼかしたグラデ図形＝全部 Figma のベクター。素材の形にマスクし、色も素材から拾える。GIF・連番で"動かせる"のは、この3つで Siren だけ。信号は、点（打点）から始まる。

What it is

点を、打つ。鳴物

Siren（鳴物）は"打楽器"だ。鳴物とは打楽器の総称。見えないグリッドの上をシーケンスが一周し、キックが鳴った角度のセルが沈む——近いほど深く。5つの声は5枚の絵ではなく、同じ面への5つの演算。リズムが、手の代わりに図形を置いていく。

デザインを"作曲"するのではない。もとからそこにあったリズムを、面の起伏で聴かせる。殴った跡は、沈むと同時に光る（ぼかした放射グラデ）。出てくるのは全部 Figma のネイティブノード＝あとから色も形も変えられる。点（打点）の Siren、面（連続）の Onore、質感の Kaibou。

How it works

16ステップ、面に刻む。

各ボイスをシーケンサーの16ステップに打ち込む。キックは凹ませ、スネアは裂き、ハットは当たった所を細かく割り、ベースは弧で持ち上げ、リムは平らを削って斜面を残す。色は選択した素材から拾える。▶ で回し、GIF・連番に書き出せば、リズムがそのまま"動くビジュアル"になる。

The signal chain

点 → 面 → 質感

Where the name comes from

名前は、アルバムから。

Siren（鳴物）は、99LETTERS のアルバム 『解剖図鑑 / Kaibou Zukan』 の9曲目「Siren（鳴物）」から。Onore（己）、Kaibou（解剖）も同じアルバムの曲名だ。デザインツールである前に、これはひとつの音楽作品の翻訳——楽器の役割を、そのまま画面上の道具に置き換えている。

About the artist

99letters — テクノ作家 / 木下貴博

99letters は木下貴博（木下スタジオ）の音楽名義。2021年に 99letters 名義へ回帰し、アルバム『解剖図鑑（Kaibou Zukan）』は Bandcamp Daily の Album of the Day に選出。音楽で培った"信号を組み立てる手つき"を、そのままデザインの道具にしたのが SHIAN 志庵——Siren / Onore / Kaibou はその最初の3つ。
