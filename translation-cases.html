TRANSLATION CASES — 体験翻訳の実績

届けたい体験と、届いている体験。
そのズレを訳した記録。

見た目を整える前に、「誰が、何を知って来て、何を持ち帰れば成功か」を決める。そこから、サイト・仕組み・運用までを同じ手で訳してきた実績を並べています。

FOR DECISION MAKERS

決める立場の方に、先にお伝えしたいこと

01
作る前に、前提の食い違いを見つける

資料の表と本文、前の計画と今の計画。ズレたまま作ると、出来上がってから直すことになります。

02
成功を「画面の上の行動」で決める

「伝わる」「ファンになる」ではなく、「事例を1つ開いた」「資料を1点持ち帰った」。測れる形にしてから作ります。

03
作ったあとに回る仕組みまで

記事の書き方の手引き、画像を作る手順、会議の回し方。担当が替わっても同じ質で続く形で渡します。

実績

5 CASES
CASE 01CLIENT × WEB
道頓堀 屋台村 祭
飲食・観光／Webサイト・ポスター
ズレ
「祭りの空気」を届けたいのに、Web ではメニューとアクセスだけの「食べに行く場所」になっていた。
訳した
人・間・声・気の4つを軸にサイトを組み直し、5言語と予約フォームを実装。
120%リニューアル後の予約率設計と画面を見る →
CASE 02BRAND × WEB
ブランドサイトのリニューアル
ライフスタイルブランド／社名は伏せています
ズレ
店舗のお客さまが感じている良さが、サイトでは届いていなかった。
訳した
店舗のアンケートとカスタマージャーニーから構成を設計し直し、公開後の運用と SNS まで担当。
約2.4倍問い合わせ 月50件前後 → 120件
CASE 03ENTERPRISE × UX
会員制ナレッジサイトの中に、事例の特設ページをつくる
大手企業の業務改善の事業部／名称は伏せています
ズレ
資料の表と本文で、メインの相手が食い違っていた。既存サイトから来る人と、検索で来る人とでは、知っていることが正反対。
訳した
ゴールを「自分に近い事例を1本見つけ、社内で話せる材料を持ち帰る」の1文に。達成を画面の上の行動で決め、記事の手引き・画像の作り方・会議の回し方まで設計。
体験設計の流れを見る →前提の変化から運用まで、順に
CASE 04IN-HOUSE × WEB
専門商社のコーポレートサイト
専門商材の商社／社名は伏せています
ズレ
専門的な商材を、詳しくない担当者にも分かる形で届ける必要があった。
訳した
リニューアルから8年間、社内で設計と運用を担当。展示会のディレクションも。
月200件問い合わせ（月間PV 7,000〜8,000）
CASE 05MUSIC × CULTURE
99LETTERS Gagaku Techno
音楽／レコード・アートワーク
ズレ
雅楽・和楽器の音には、今のクラブ文化の中で届く文脈がなかった。
訳した
伝統楽器の音を失わず、テクノ・インダストリアルの構造に訳した。
海外リリース国際レーベル Phantom Limb / Disciples から。Resident Advisor・Bandcamp Daily・NTS Radio ほか海外のメディアで紹介作品と経緯を見る →
CASE 06ENTERPRISE × SALES DECK
営業担当が商談で使う資料を、相手が話し始める順につくる
大手企業の営業統括の部署／名称は伏せています
ズレ
これまでの資料は、サービスを並べる順で、相手が知りたい順ではなかった。事例も、業界ではなく営業のやり方で探されていた。
訳した
目的を「興味 → 質問 → 課題を確かめる」に言い直し、並びを相手の頭に浮かぶ問いの順にした。良し悪しは商談で起きたことで測る。
体験設計の流れを見る →目的の言い直しから評価の物差しまで、順に
CASE 07ENTERPRISE × LOGO
仕事の進め方の方法論に、ロゴと使い方の決まりをつくる
大手企業の業務改善を担う部署／名称は伏せています
ズレ
3つのサービスに1対1で当てた3色が、サービスの数が変わると意味を失う作りになっていた。
訳した
3色を、変わらない「考え方 → 仕組み → 成果」の3段に当て直し、4色目を足さない決まりにした。
体験設計の流れを見る →定義の言葉から使い方の決まりまで、順に
CASE 08ENTERPRISE × RECRUITING UX
社員紹介の採用サイトを、「読ませる」から「渡させる」へ組み直す
大手企業の人事の部署／名称は伏せています
ズレ
社員向けのページが制度の説明として作られていて、紹介に必要な道具が下のほうに埋もれていた。
訳した
ゴールを「読ませる」から「渡させる」に置き直し、並び・渡す道具・社外向けへのつなぎ目まで組み直した。
体験設計の流れを見る →2つのサイトの見立てから、つなぎ目まで、順に
CASE 09PUBLIC × PRINT SERIES
読む人の違う紙ものを、1つの版から何枚もつくる
公共の事業の運営事務局／名称は伏せています
ズレ
1つの版を使い回すと、目的の違う3枚が同じ構成になる。同じ人が受け取る紙ほど、区別がつかない。
訳した
共通の「版」と目的ごとの「型」に分けた。読む人の違う2枚は揃え、制作物ごとに型を変えた。
体験設計の流れを見る →現物の確認から、刷る・使い続けるまで、順に

社名・ブランド名は、お客さまとの約束により伏せているものがあります。数字は公開・運用時点のものです。
