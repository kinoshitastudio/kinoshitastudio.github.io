デザインで揃える。

ブランドが持つ思想と、顧客が実際に受け取る体験の間には
必ずズレがある。

CONCLUSION — 結論

体験翻訳家とは

お店・会社・作品がもっている体験から始めて、
見た目にも、音にも、触れる形にも訳し、自分の手でつくって渡す人。

デザイン会社に頼むコンサルに頼む体験翻訳家に頼む
始まり「ロゴを」「サイトを」品目から課題の診断からその店・作品の体験から
渡すもの頼んだ品目方針・報告書（言葉）訳したもの（形・音・触れる仕掛け）
扱う感覚見た目言葉見た目・音・触れる・動き
つくる人品目ごとに別の担当別の制作会社同じひとり

頼めること

頼めるもの具体的にはこんなときに
ロゴ・題字・看板名前の字を、一点もので作る開店・リニューアル・周年
ポスター・チラシ・パッケージ映画や商品の空気を、1枚に映画の公開・イベント・新商品
Webサイト見て、触れて、覚えてもらえるサイトお店・会社・作り手の紹介
音お店のBGM・音のロゴ・映像の音店の空気を揃えたいとき
動く映像ポスターがそのまま動く短い映像・予告SNS・映画・イベントの告知
触れる展示・Web触ると反応する仕掛け周年・展示・学校や研究の紹介

見た目と音を、ひとりで、同じ考えでつくる。だから、ズレない。

TRANSLATION MODEL
SOURCE — 原文
オーナーが
届けたい体験

ブランドが持つ思想、世界観、
届けたいと思っている感覚。
多くの場合、言語化されていない。

たとえば「静かで、深い湖」

TRANSLATE
OUTPUT — 訳文
顧客が実際に
受け取る体験

サイト、SNS、空間、接客、商品——
あらゆる接点で顧客が感じるもの。
多くの場合、原文とズレている。

届いているのは「大きい湖」だけ

このズレが大きいブランドほど、「伝わらない」「選ばれない」という問題を抱えている。
体験翻訳家は、このズレを発見し、揃える。

TRANSLATION CASES — 翻訳の実績
CASE 01
CLIENT × WEB
道頓堀
屋台村 祭

サイトリニューアル後

予約率120%アップ

「料理を食べる場所」を、「祭りの空気を体験する場所」へ。

INPUT
串カツ・海鮮・お好み焼きの屋台が並ぶ、道頓堀川沿いの屋台村。Webでは、メニューとアクセスだけの「食べに行く場所」としてしか伝わっていなかった。
PROCESS
届けたい体験は料理ではなく「祭りの空気」だと読み、人・間・声・気の4つを軸にサイトを組み直した。5言語に対応し、予約フォームを実装。
OUTPUT
サイトリニューアル後、予約率が120%アップ。Web・SNS・現場のサインまで、同じ「祭りの空気」が届くように。
Webサイトの事例を見る →ポスターの事例を見る →
CASE 02
BRAND × WEB
ブランドサイトの
リニューアル

ライフスタイルブランド ── リニューアル後の問い合わせ

約2.4倍

INPUT
実店舗のお客さまが感じているブランドの良さを、サイトでどう届けるか。
PROCESS
実店舗でのアンケートとカスタマージャーニーをもとに、サイトの構成を設計し直した。公開後のコンテンツ運用とSNSも担当。
OUTPUT
月間PV 10,000〜12,000 → 15,000〜17,000。問い合わせ 月50件前後 → 120件（約2.4倍）。
CASE 03
IN-HOUSE × WEB
専門商社の
コーポレートサイト

8年、社内で設計・運用したサイトの問い合わせ

月200件

INPUT
専門的な商材を扱う会社の、コーポレートサイト。
PROCESS
社内のデザイナーとして、サイトのリニューアルから8年間の運用まで。展示会のディレクションも担当。
OUTPUT
月間PV 7,000〜8,000、問い合わせ 月200件のサイトとして運用。
ここからは、自主制作での翻訳
CASE 04
MUSIC × CULTURE
99LETTERS
Gagaku Techno

雅楽の音を、クラブで鳴る音へ。

INPUT
雅楽・和楽器という伝統的な日本の音。現代のクラブ文化の中で届く文脈がない。
PROCESS
伝統楽器のDNAを失わず、テクノ・インダストリアルの構造に翻訳。琴・篠笛・打楽器をノイズとドローンで再構成。
OUTPUT
国際レーベル Phantom Limb / Disciples からリリース。Resident Advisor・Bandcamp Daily・NTS Radio など、海外のメディアで紹介された。

SERVICES — 提供できること

ズレを見つけた人が、最後まで作る。

考える人と作る人が分かれると、その間で、またズレが生まれる。
木下スタジオは、体験を読むところから、
できあがった物を渡すところまで、同じ手でやる。

— 01
体験を読む
Read

話と現場から、お店や作品の体験を読み取る。
何が「らしさ」で、どこがズレているかを、
1枚にまとめて共有する。

— 02
訳して、つくる
Translate & Make

字・ポスター・Web・音・映像・触れる仕掛け。
読んだ体験にいちばん合う形を選び、
自分の手でつくる。

— 03
揃え続ける
Keep

納めたあとに増えていく物も、同じ考えで揃える。
必要なときだけ、月ごとの相談も受ける。

HOW IT WORKS — 進め方
  1. 01

    話を聞く

    お店や作品のこと、届けたいこと。約2時間。

  2. 02

    体験を読む

    らしさとズレを、1枚にして共有する。

  3. 03

    訳して、つくる

    字・形・音・Webを、同じ考えで。

  4. 04

    渡す

    納品。そのあとも、必要なら月ごとに。
