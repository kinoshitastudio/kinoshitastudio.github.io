GitHub 設定
画像を直接アップロードするために GitHub Personal Access Token が必要です。
github.com/settings/tokens/new で Contents: Read and write 権限を持つ Fine-grained token を作成してください。
Token はこのブラウザの localStorage にのみ保存され、外部に送信されません。
末尾に / を付けてください。例: assets/projects/research/
