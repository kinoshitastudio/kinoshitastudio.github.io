01 AUDIO 鳴る
0:000:00
低音 → 厚みが脈打つ・層が開く／中音 → 版がうねる・滲む・色相
高音 → 刻み・回転／キック → 版が裏返る・露光が飛ぶ
02 CAMERA 写す
SKIN = いまの自分がそのまま立体になる（＝入口）。TINT の 纏 WRAP が帯を法線に巻きつける
SKIN を 0 に戻すと版モード（彫 = 動いた軌跡だけが彫られる／写 = 止まると彫られ動くと削れる）
FADE = 触られない版が埋まって戻る速さ
03 MOTION 動く
動きも音と同じくチェーンを叩く（2本目の変調源）
LED を落とすと削れない＝ただのベタ写しに戻る
04 RELIEF 彫る
LAYER > 0 で等高線のスライスに割れる
音（低音）で層が前後に開く
05 HATCH 刻む
WALL = 等高線に沿って刻みが走る（急勾配だけ）
06 BLEED 滲む
FLIP を上げると反転が出る
CYCLES > 0 でリングが内側から湧き続ける
07 TAPE 通す
08 TINT 差す
纏 = 映るものから採ったグラデーションが面の向きにまとわりつく
HUE = 帯をスライド／SHIFT = 帯の向きを回す
VIVID = 帯の彩度（部屋の色は放っておくと濁る）
SAT 0 でモノクロームに戻る
MOVE — 彫られる
STAY STILL — 紙のまま
DRAG — 回す / WHEEL — 寄る
