# 写真の物を足す（mock/）

⭐⭐ **この道具の値打ちは「なじませる」側にある**。物そのものは、写真の方がずっと生々しい。
だからここに写真を置けば、描いた物と同じように **一覧に並んで、押すだけで使える**。

## 3手でおわり

1. **写真をこのフォルダに置く**（`tshirt.jpg` など。jpg / png / webp）
2. `list.json` の `items` に1行足す

```json
{ "items": [
  { "file": "tshirt.jpg", "name": "Tシャツ（写真）" }
] }
```

3. 開いて、その物を押す → 盤の**四隅を掴んでロゴを乗せたい所に合わせる**
   → **「いまの四隅を写す」**を押すと、下の `faces` に貼れる形でコピーされる

```json
{ "file": "tshirt.jpg", "name": "Tシャツ（写真）",
  "faces": [[[0.34,0.36],[0.66,0.36],[0.66,0.58],[0.34,0.58]]] }
```

`faces` を書いておくと、**次からは押すだけで位置が合う**。書かなければ真ん中に出る。
面は何枚でも書ける（箱の正面と側面／Tシャツの胸とタグ）。

## 決め方

- ⭐ **陰影としわがはっきりした写真ほどよく馴染む**（借りるものが多いから）。
  真っ平らで白飛びした写真は、何を借りても「貼っただけ」になる。
- ⚠️ **四隅は 左上→右上→右下→左下 の順**。順を崩すと絵が裏返る。
- 🔴 **権利は写真ごとに違う**。企業案件の提案に出すなら、商用可・帰属不要のものか、
  自分で撮ったものを置くこと。ここに置いた写真はサイトと一緒に公開される。
  （描いた物のほうは、この道具の中で描いているので権利の心配がない）
- 写真は長辺 2000px 程度で十分。大きすぎると開くのが遅くなる。
