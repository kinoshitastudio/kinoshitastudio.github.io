Siren · 点 — concept lookbook

あなたのマークを、
鳴らす。点で何が作れるか

Siren は「点」。自分の部品（ロゴ・記号・図形）を、リズムで 撒いて・並べて・動かす。出てくるのは、あなたのマークでできた 動くパターン／モーション ── それを GIF・連番 で書き出す。
下は「何が作れるか」の見本（全部 同じ1つのマークを鳴らしているだけ・全部 動いている）。

FIELDパターン
マークを敷き詰め、リズムの波でスケールが脈打つ。ブランドの「動く地紋」。
→ 背景ループ / SNS壁紙 / ヒーロー地
ASSEMBLE集合⇄拡散
散らばったマークが形（円・文字・ロゴ）に集まり、また散る。組み上がる瞬間が主役。
→ ロゴスティング / イントロ / リビール
BURST打点
ビートごとに中心からマークが放射で弾ける。エネルギーの塊。
→ アクセント / ポスター / キメの1枚
FLOW流れ
マークがフロー場に沿って流れ続ける。方向と速度が生む「気配」。
→ ローダー / 常時ループ / 環境映像
STEP 1616歩
16ステップがそのまま格子に。再生ヘッドが順に点灯＝シーケンサーが絵になる。99letters の音楽DNA直結。
→ 音楽的ループ / MV素材 / 自己紹介
ORBIT軌道
複数の半径・速度でマークが周回。整然と、でも生きている。
→ シンボル / アイキャッチ / 待機画面

この見本で言いたいこと

① ゴール＝「自分のマークでできた"動く"グラフィック（ループ）」。静止画に流し込むのではなく、リズムで振り付けるのが Siren。

② だから 動く（GIF/連番）が主役。面がシーケンスで遊べて楽しいのと同じ楽しさを、点は「自分の部品で」やる。今のプラグインの点は"止まっている"＝そこが欠けている核心。

③ ユーザーが自由にできること＝撒き方（分布）を選ぶ：FIELD / ASSEMBLE / BURST / FLOW / STEP / ORBIT…。これが「自由度」の正体。ブロブ1種ではなく、並べ方のメニュー。
