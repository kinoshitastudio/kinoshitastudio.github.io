これからのアップデート（予定）

公式AIは、UIをつくる。
Mothershipは、その手前＝"なぜ"を立て、整え・蓄積・自動化する。

会話でモーション — 選んだフレームに会話でキーフレームを設計。予備動作・オーバーシュート・スタッガーの効いた動き、映画的なスライドショー、増殖パーティクル（星が流れる等）まで。 V3・近日
パス整形 — ベクターのガタついたパスを、形をキープしたまま簡略化＋スムーズ（RDP＋曲線fit）。会話編集では扱えなかったパス編集に対応。 V3・近日
relay 自動起動 — node setup.js で以降ログイン時に自動起動（落ちても自動再起動）。端末を開き続ける必要がなくなり、接続が“必ず通る”。 V3・近日
チーム独自のシステムを育てる — 既製のデザインシステムに“合わせる”のではなく、貯めた原本JSONから、あなたたちグループ固有の型・トークン・語彙を蓄積。チームだけの設計言語になる。 進行中
デザインシステム同期 — 色→Variables・文字→Text Styles の自動トークン化を第一歩に、トークン／コンポーネントを GitHub のコードと照合・同期。 トークン化＝開発中
URL再現の精度向上 — 再現自体は動作中。取りこぼし要素を減らし、複数セクションを連結。スプライト文字の地を透過に。 一部実装済
データ駆動の量産 — 手動JSON生成は可。CSV / JSON を流し込んで大量のフレームを一括生成へ。 予定
⟨⟩コード出力（HTML / React） — 同じ原本JSONから、実装コードも書き出す。デザインとコードを一つの原本から両出力。 予定
コンポーネント整理 — 野良要素を既存コンポーネントへ置換、バリアントを自動でまとめる。 予定
頭脳を交換 — Claude／Codex／Gemini をパネルで選べる（検出済みのみ有効）。原本はJSONだから、次のAIも差せる。 エンジン選択＝実装済(V3)

※ ステータスは目安。進行中／開発中＝着手済、予定・構想＝検討中。順次アップデート。
