## ⚠️ 分かっている落とし穴

- **webp/avif は Figma が描けない** → JPEG に変換してから
- **300KB超の画像は relay が切り捨てる** → 1ファイルを軽くする
- **`<br>` 入りの見出しは「子要素0個」判定だと落ちる**
- **ヘッダーは `<section>` の外**（position:fixed）→ 先頭セクションに合成
- **背景 transparent** → 親をさかのぼって実際の色を取る
- **clip-path の斜めカット** → 🔴 自動では出せない

## ⭐⭐ 心臓 ── 位置を padding と gap に翻訳する

```
padStart = 最初の子の始まり − 親の始まり
padEnd   = 親の終わり − 最後の子の終わり
gap      = 次の子の始まり − 前の子の終わり
```
⭐ 座標を1つも書かずに同じ絵が出る。しかも**書体が変わっても壊れない**。

## 🔴 写真が入らない時（実測で潰した4つ）

| 症状 | 正体 | 直し方 |
|---|---|---|
| 🔴 **真っ白な写真が焼ける** | 同じ場所に `<img>` と `::before` の背景の2枚。空の方を採っていた | **実物のURLがある方**を採る |
| 🔴 **1×1 の data URI** | `class="lazyload"` は**読み込まれていない**。本物は `data-src` | 測る前に `data-src → src` に流し込む（60枚以上あった） |
| 🔴 **中身の無い svg プレースホルダ** | 交差フェードの「次の絵」（Studio系） | **`data:` の画像は写真ではない**と扱う。実物が無ければ灰色の枠に |
| 🔴 **`.svg` が描けない** | `bake.js` の `mimeOf` は svg を **jpeg 扱い**する | URLの中身を取ってきて **`svg` ノード**に差し替える |

## ⭐⭐ 解けない所は「スクショを敷く」

> 木下「こういう複雑な難しいやつは、構成そのままでなく**スクリーンショット的な感じで画像だけ置いていてもいい**」

⭐ **KV は丸ごとスクショを1枚敷いて、その上に 文字とロゴだけ 乗せる。**
　（クロスフェード・スライドショー・重なりは、URLを当てにいかず見た目を焼く）
⭐ **未読込の写真（灰色の枠）も、その場所のスクショに差し替える。**
⚠️ 文字はスクショにも焼かれている＝**二重に見えるならテキストレイヤーを消す**／
　逆に**文字が要るならスクショを消す**。どちらもレイヤーで分かれている。

🔴 これを入れるまで、H-7 の KV は**矢羽根のオーバーレイ画像だけ**を拾っていた
（女性の写真はクロスフェードの裏側に居て、URLでは当てられなかった）。

## 🔴 ほかに潰した所

| | |
|---|---|
| **中央寄せの余白は均等とは限らない** | `padding-bottom:30` で 15px ずれた。<br>`d = 2×(中身の中心 − 箱の中心)`／`d≥0`は上に`d`、`d<0`は下に`−d` |
| **はみ出す子は表せない** | 2枚以上はみ出したら**1枚に束ねて、その帯だけ絶対配置**（マーキー写真64枚が 61個→2個） |
| **入れ物を畳みすぎる** | ⚠️ **セクション自身は畳まない**（余白240pxと高さを丸ごと失う） |
| **ヘッダーの重複よけ** | ⚠️ x/y/幅 だけで比べると**KVと同一視して捨てる**。**高さも見る** |
| **`<br>` の偽の改行** | `pc_hidden` は PC で `display:none`。**display を見てから**改行にする |
| **疑似要素** | 矢印・丸・帯は `::before/::after`。**DOM に出ない**ので別に拾う |

## ⚠️ 書体は寄せる前に「折り返しが変わらないか」測る

⭐ 本文14px／225px幅 → Noto Sans JP でも **2/1/2/2行**＝元と同じ。
🔴 ただし**ボタンの文字は Noto のほうが 3.7px 広い**（205.9 → 209.6）。
　→ **短いラベルに `w` を入れると折り返して壊れる。hug（`w` を書かない）。**
　→ 長い本文は `w` 必須。**使い分ける。**
⭐ 明朝→`Noto Serif JP` ／ Cormorant→`Cormorant Garamond` ／ 和文ゴシック→`Noto Sans JP`。

## ⭐ レイヤー名

クラスが `sd / wrap / inner / box / item / row / list / content` だと意味が無い。
→ **中の最初の文字**を名前にする。文字が無ければ 小さければ「アイコン」大きければ「写真」。
