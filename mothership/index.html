ありがちな取り込み

html-to-design 系＝丸ごとダンプ

DOMをそのまま数百レイヤーの深いネスト＋絶対座標で吐く。命名もオートレイアウトもトークンも無い“汚い1:1コピー”。結局、整えるのに時間がかかる。

Mothershipの再現

AIが理解して、綺麗に建て直す

全体を雑に取らず、KV等の1セクションをAIが“意味”で再構成。オートレイアウト・トークン・命名つきの、あなたが所有できる原本JSON。

✅ いま再現できる

レイアウト・配色・余白・タイポ（算出値どおり）／実テキスト／写真（実画像・webpも）／ロゴ・見出しのSVG／縦書き等のスプライト文字（実画像で採取）。

🔧 いま改善中

ナビ等の取りこぼしを減らす“完全性”の向上／スプライト文字の地の透過／複数セクションの連結。

⛔ 原理的に難しい

動画・アニメのヒーロー（静止では再現不可＝プレースホルダ）。専有フォントは Figma に無ければ近い代替に。

※ ゴールはピクセル完全コピーではなく「URL → 綺麗で編集可能な“8割の叩き台”を一瞬で」。残りはあなたが詰める。

The one source of truth

ひとつのファイルが、
設計の原本になる。

Mothershipは、デザインを mothership.json という一枚の原本として持つ。 Claude Code が"コードを書くのと同じ"でそれを編集し、プラグインが 本物のFigmaノードとして建てる。 SVGの貼り付けではない。テキストもオートレイアウトも、そのまま編集できる。

作る · 詰める · 貯める

終わらない、生成のループ。

01 — 作る

チャットで生まれる

「料金表を作って」。言葉で依頼すると、claudeが原本を書き、接続中のFigmaにネイティブで生成される。ゼロから手を動かす疲れを消す。

02 — 詰める

感覚で、詰める

余白・フォント・プロポーション。参照画像を重ねて当て込み、ズレを見て数値で詰める。ここの精度こそが価値。

03 — 貯める

資産になる

詰め切ったデザインはライブラリへ。貯めるほど精度が累積し、次の一枚が速くなる。あなただけの設計の蓄積。

No-MCP · runs on Pro / Max

中心は、AIではなく原本。

原本はただのファイル。だからAIが直接編集できる。MCPは不要、API課金も不要——Claude Code の Pro / Max だけで、チャットからFigmaまで完結する。 そして中心に置くのはAIではなく、原本のJSON。だからAIは交換可能になり、モデルが変わっても資産は残る。relayとプラグインはAIを一切呼ばない、ただの配管とレンダラー。

なぜMCPを採用しないのか →
いま、そしてこれから

つくるAIは、Figmaへ。
Mothershipは、その先を。

「生成」はFigmaのAIが担う時代へ。Mothershipの価値は、所有・整える・自動化に移る。

できること

つくる、そして整える。

チャットでネイティブ生成。さらに選択画面の構造を読み、レイアウト崩れ・命名・浮いた要素を整える。原本は、あなたが所有するJSON。

誰のために

資産として、持つ人へ。

デザインを資産にしたい人。デザインシステムをコードで運用する開発寄りデザイナー／チーム。公式AIの生成物を、実装できる形に整えたい人。

これから

頭脳は、交換可能。

Claude も Gemini も次のAIも、頭脳として差し替えられる。「公式AIがつくる」×「Mothershipが整え・自動化する」——共生のレイヤーへ。

これからのアップデート（予定）

公式AIが「つくる」。
Mothershipが「整える・自動化する」。

🔍構造を読む — 「この画面、何のレイヤーが何個？」を解析して可視化。
🧹整える（Lint & Fix） — 公式AIが作った崩れ（Autolayout・命名・非コンポ・フォント揺れ）をワンクリック一括修正。
🧩コンポーネント整理 — 野良要素を既存コンポーネントへ置換、バリアントを自動でまとめる。
📊データ駆動の量産 — CSV / JSON を流し込んで、大量のフレームを一括生成。
🔗デザインシステム同期 — トークン／コンポーネントを GitHub のコードと照合・同期。
🔁頭脳を交換 — Claude も Gemini も、次のAIも。原本はJSONだから縛られない。
⟨⟩コード出力（HTML / React） — 同じ原本JSONから、実装コードも書き出す。デザインとコードを一つの原本から両出力。
🌐URL再現の精度向上 — 取りこぼし要素を減らし、複数セクションを連結。スプライト文字の地を透過に。

※ 予定・検討中の機能です。順次アップデート予定。
