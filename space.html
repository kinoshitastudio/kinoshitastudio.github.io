// 01 — primary tool
N O A

iPhone から Claude Code を操作するために作ったブラウザターミナル。TERM / EDITOR / FILES の3カラム構成。音声入力・横スワイプ切替・コマンドパレット対応。

01
PTY セッション
プロジェクトごとに独立した端末。複数並行。
02
3カラム表示
TERM / EDITOR / FILES を同時表示。
03
モバイルファースト
iPhone からタップ操作。Claude Code を外出先で。
04
Tailscale 対応
どこからでも同じURLでアクセス可能。
05
セッション共有
PCの作業をそのまま iPhone で確認。
06
4テーマ
