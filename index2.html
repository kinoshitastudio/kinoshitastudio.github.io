001 — Why / なぜ伝わらないのか

「伝わらない」には、
構造的な理由がある。

デザインが問題なのではありません。
「届けたい体験」と「届いている体験」の間に
ズレが生まれているのです。

— 01 / Information Gap

情報はある。
でも、使われない。

整理された情報は「制度」として届く。人は制度を読まない。自分ごとの文脈に置かれた時だけ、動く。

— 02 / Meaning Gap

価値がある。
でも、伝わらない。

「良さ」は作り手の文脈で語られることが多い。価値が機能するのは、相手が自分ごとして受け取れた時だけ。

— 03 / Action Gap

理解された。
でも、行動されない。

「わかった」と「動く」は別のこと。行動を生む導線と感情的な確信が設計されていないと、人は止まる。

003 — Process / 仕事の流れ

思想 → 証明 → 行動。
3つのフェーズで整える。

「伝わらない」の原因は必ず特定できます。
観察・設計・実装の3フェーズを通じて、
届けたい体験を届く形に翻訳します。

Phase 01 — Diagnosis

Observe.

ズレ診断

現状の問題を可視化する。ユーザー視点での違和感を抽出し、「なぜ伝わらないのか」の構造的な理由を明らかにします。

— Output

体験マッピング
ズレの可視化・言語化
改善の優先順位整理

Phase 02 — Translation

Translate.

体験翻訳設計

意味を再定義し、受け取られ方を変える。「届けたい体験」と「届いている体験」のズレを埋める構造・言語・導線を設計します。

— Output

体験翻訳マップ
コピー言語化
導線・情報設計

Phase 03 — Implementation

Implement.

実装

設計を、感じられる形にする。UI・ビジュアル・空気感・質感まで、体験として届く形に落とし込みます。

— Output

UX / UI Design
Web・プロダクト実装
体験設計顧問（月次）
