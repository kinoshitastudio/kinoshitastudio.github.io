PIXEL BOMB

Collapse an image into itself using ranked pixel blocks.
Blocks of high local complexity (variance) are selected first and pulled toward the center, iteratively. The image implodes into its own center.
Launch app →
Controls
[o] Load image (or paste / drop)
[p] Save result as png
[r] Reset to original
[h] Step back
[l] Step forward
Inspired by Collapse by Constraint Systems.
