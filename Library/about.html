コンセプト

スタジオの本棚を、開いた。

Are.na や Notion に書き留めてきた本の記録が、いつしか膨らんだ。 それをそのまま外に出せる空間が欲しかった。ランキングも、レビューも、 いいね数もない——ただ本が並んでいるだけの場所。

「本棚は人格だ。」

デザイン・建築・写真・哲学・音楽・小説。ジャンルを横断しながら並ぶ本の配置に、 読み手の思考のクセが滲み出る。このライブラリは木下スタジオのそれを公開したものでもあり、 あなた自身の本棚を作るためのツールでもある。

機能

本棚として必要なことを、過不足なく。

01

150冊以上のキュレーション

木下スタジオが選んだデザイン・建築・写真・哲学など。スタジオの本棚がそのまま並ぶ。

02

Open Library 書籍検索

世界中の本を検索して自分の棚に追加できる。Open Library API を直接利用。

03

AI 書籍検索

「静けさについての本」「建築と光」など曖昧な言葉で探せる Gemini 連携機能。

04

ドラッグ並び替え

本を自由に動かして、自分だけの順番を作れる。配置はブラウザに記憶される。

05

窓の光シミュレーション

時間帯によって本棚に差し込む光の角度が変わる。朝と夕方で表情が違う。

06

ナイトモード

18時以降、自動で暗い本棚に切り替わる。手動でも切り替えられる。

ナイトモード

18時を過ぎると、本棚が暗くなる。

昼と夜で本棚の見え方が変わる。光と影が、本の選び方も変えるかもしれない。

22:14 — NIGHT MODE

深い茶の木目と沈んだ紙色。本のタイトルがぼんやりと浮かぶ。

使い方

ブラウザで開くだけ。

アカウント不要。インストール不要。URLを開けばすぐ使える。

01
ブラウザで開く
kinoshita.studio/Library/ にアクセスするだけ。サインアップ不要。
02
本を探す
「検索」タブから本のタイトル・著者名・あるいは曖昧なキーワードで検索。AI検索も使える。
03
本棚に並べる
「本棚に追加」→ドラッグで好きな場所へ。配置はブラウザに自動保存される。
