001 — Studio

いいものなのに、
伝わっていない。
それは、ズレです。

情報はあるのに使われない。
魅力があるのに伝わらない。
理解されても行動されない。

届けたい体験と、届いている体験の間にある
構造的なズレを発見し、整える。
「伝わらない」を「行動される」に変える設計を行います。

ズレを一緒に整理する 仕事の流れを見る 体験翻訳家とは何か

届けたい体験届いている体験

— Self Check / こんな状態になっていませんか

  • いいものを作っているのに選ばれない
  • 情報があるのに使われていない
  • ユーザーが途中で離脱してしまう
  • ブランドに世界観はあるが言語化できない
  • デザインは整っているのに体験がバラバラに見える

ひとつでも当てはまるなら、
それは「ズレ」が起きているサインです。
その違和感には、構造的な理由があります。

002 — Service / できること

木下スタジオは
「伝わらない」を
「行動される」に変える設計を行います。

ブランド・Web・プロダクト・採用——
思想が伝わらない、体験がバラバラに見える、
そのズレを発見し、整える。
滋賀県を拠点に、UX/UIデザインを軸とした体験設計を行うスタジオ。
木下貴博が一人で運営しています。

— 01

Phase 01 — Diagnosis

ズレ診断

どこで伝わっていないのかを、お客さまの目で確かめます。

現状の問題点を可視化する。
ユーザー視点での違和感を抽出し、
「なぜ伝わらないのか」の構造的な理由を明らかにします。

  • 現状の体験マッピング
  • ユーザー視点での違和感抽出
  • ズレの構造的な可視化・言語化
  • 改善の優先順位の整理

— 02

Phase 02 — Translation

体験翻訳設計

伝える言葉・順番・入口を、組み直します。

意味を再定義し、受け取られ方を変える。
「届けたい体験」と「届いている体験」のズレを埋める
構造・言語・導線を設計します。

  • 意味の再定義・コピー言語化
  • 体験構造の設計
  • 行動を生む導線設計
  • 情報アーキテクチャの再構築

— 03

Phase 03 — Implementation

実装

サイト・ポスター・画面として、実際に形にします。

設計を、感じられる形にする。
UI・ビジュアル・空気感・質感まで、
体験として届く形に落とし込みます。

  • UI / ビジュアル設計
  • 空気感・質感の設計
  • Web・プロダクト実装
  • 体験設計（継続支援）

003 — Cases / 実績

制作物ではなく、
変化を記録します。

何をつくったかではなく、何がどう変わったか。

— 01

社内UX / 情報設計

課題

社員が情報を探さなくなっていた

ズレ

情報が「制度」として整理されていた。人は制度を読まない。

翻訳

「人生イベント」単位で情報を再設計。制度ではなく、自分ごとの文脈に置き換えた。

結果

迷いが減り、行動導線が明確化。情報への自発的なアクセスが増加。

— 02

Web / ブランド体験設計

課題

世界観はあるのに、サイトが「カタログ」になっていた

ズレ

商品の情報が整理されていた。しかし人は「体験したい場所」を探している。

翻訳

「どんな体験ができるか」を起点に構造を再設計。感情の動線から情報を配置した。

結果

滞在時間の延長、問い合わせ率の改善。「雰囲気が伝わった」という声が増加。

— 03

アプリ / UX設計

課題

機能はあるのに、使われなかった

ズレ

「できること」が整理されていた。しかし人は「自分の今」から動く。

翻訳

「今日、何をしたいか」を起点にした導線設計。状況と感情から入る構造へ変換。

結果

初回利用完了率が改善。リピート利用に繋がる体験の定着が確認された。

004 — Gap / ズレの構造

「伝わらない」には、
構造的な理由がある。

デザインが問題なのではありません。
「届けたい体験」と「届いている体験」の間に
ズレが生まれているのです。

— 01 / Information Gap

情報はある。
でも、使われない。

整理された情報は、「制度」として届く。
人は制度を読まない。自分ごとの文脈に置かれたとき、はじめて動く。

— 02 / Meaning Gap

価値がある。
でも、伝わらない。

「良さ」は作り手の文脈で語られることが多い。
価値が価値として機能するのは、相手が自分ごとして受け取れたときだけ。

— 03 / Action Gap

理解された。
でも、行動されない。

「わかった」と「動く」は別のこと。
行動を生む導線と、感情的な確信が設計されていないと、人は止まる。

005 — Contact

「伝わらない」と
感じている部分を
教えてください。

まずはズレを一緒に整理しましょう。
課題が言語化できていなくても構いません。

「なんか伝わってない気がする」でいい。
そこから始めます。
