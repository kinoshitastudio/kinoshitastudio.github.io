インクは減る・版は動く・紙は平らでない

2026.10 Tool / Print
← 体験研究の一覧へ

インクや塗料は、何回もスタンプすると掠れてくる。普通のスキャナーでは、それが出せない。スキャナーは紙を押さない。ガラスの上を横から読んでいるだけだ。それなら、上から塗料で紙に刷って、どんどん掠れていく道具を作ろう。そう決めて作ったのが 捺 NATSU だ。

芯は1行

インクは減る。版は動く。紙は平らでない。

かすれは乱数ではない。2つの地形の引き算で出る。紙の目の山と谷、それと版の凸。インクが薄くなるほど、紙の山にしか届かなくなる。

掃 SOU との違い

先に作った掃 SOU も、刷りの道具だ。違いはそのまま設計になった。

掃 SOU捺 NATSU
何が起きているか光が読む。触れていない物が触れる
かすれの出どころ焼き・にじみ・二値。光学インクが減る・紙の山。物理
分けてあるもの版と現像版・インク・紙の3つ
同じ操作を2回同じ絵（種つき）2回目は薄い。状態が残る
やり直し何度でも現像し直せる減ったインクは戻らない

いちばん大きい違いは、前の1枚が次に効くこと。

盤の上にあるもの

  • 版　かたち（打った字、読み込んだ地なしの画像）と、凸の高さ。
  • インク　版の上に乗っている量。押すたびに減る。足せる。
  • 紙　種から決まる地形（目の粗さと向き）と、刷られた面。

3つを別々に持つ。1枚の絵に混ぜた瞬間、この道具は成り立たなくなる。

「捺す」1回の手順

  • ① 圧の場。手の傾き、どこを強く押したか。なだらかな面。
  • ② 離れ。1 から、圧・版の凸・紙の高さ・インクの厚みを引く。
  • ③ 当たり。離れが 0 を下回った所だけ、なめらかに 0〜1 で当たる。
  • ④ 濃さ。当たりにインクの量を掛ける。
  • ⑤ 紙に足す。
  • ⑥ 版から引く。
  • ⑦ 版をずらす。手で押すので、次は同じ所に当たらない。

これで「3回目から急に掠れる」が勝手に出る。カーブを描いて作らない。②のインクの厚みが芯だ。厚いほど紙の谷まで届く。薄くなると山だけに乗る。

10回刷った

既定の設定のまま、インクを足さずに10回刷った。字は既定の ABCDE〜XYZ。

道具が出す「乗った量」は、1回目 83%、10回目 32%。まっすぐには減らない。上からの圧は全体に均一にはかからないので、回ごとに違う圧の場を作ってある。圧が抜けた所は、インクがあっても刷られない。字の片側がすっぱり欠けるのはそのためだ。

字ごとの差も、一様には付けていない。一様だと、全部の字が同じだけ薄くなって、参考にした刷りから外れた。差を3乗で付けると、ほとんどの字は満タンのまま、何字かだけが大きく減る。

つまみにしないもの

「押す」と「インクを足す」は、つまみにせずボタンにした。押すたびに1回刷れる。途中でインクを足せるのも、本物と同じ。何回刷るかは、押した回数で決まる。刷ったあとも、つまみを動かすと同じ回数で刷り直すので、全部のつまみが効く。

物差し

  • 同じ種なら1画素も違わない。乱れは種から決める。
  • SVG に書き出した輪郭と画素の差は 0。
  • JSON に保存して開き直すと、差は 0 画素。位置を小数2桁に丸めたら 1,887 画素ずれたので、丸めない。

なぜ作ったか

日本語でかすれたクラシックをやると、筆書体になって和に転ぶ。書体で古さを出さずに、版の側で出したかった。題字はゴシックのまま、刷りだけが古い。この道具はその版の側を受け持つ。書体を替えずに汚す話は 題字はインクの側を汚す に書いた。
