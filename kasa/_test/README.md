# 暈 KASA の試験

    bash kasa/_test/run.sh              # 通し試験（OK だけ並べば通過）
    node kasa/_test/move.mjs            # 「動き」がどれだけ絵を変えるかを実測する
    python3 - <<'PY' ... PY             # ↓ same.mjs は先に HEAD を取り出しておく
    node kasa/_test/same.mjs            # 直す前（/tmp/kasa_head.html）と絵が同じか

⭐ **本体（index.html）は1行も触らない。** 複製の `</body>` の前に試験を差し込んで
headless Chrome で読む。`KASA` に出している入口（`paint` / `holesAt` / `ASEL` …）から測る。

⚠️ 見に行く本体は差し替えられる → `KASA_SRC=/tmp/kasa_head.html node kasa/_test/check.mjs`
（直す前と突き合わせるときに使う）

## 🔴 2026-08-25 に踏んだ型

- **Chrome が終わらずに試験が返らないことがある。** 結果は先に出ているので、
  `timeout` を付けて【途中まで出ている結果】を読む（`execFileSync` の timeout ＋ catch で stdout）
- **試験の並び順が状態を運ぶ。** 角の玉を「選んでから掴む」に変えたら、
  その先の試験（1本の指で絵がつかめる）まで落ちた＝**前の試験が作った状態**が変わったため。
  ⭐ 直したのは本体ではなく**その試験の手順**（先に絵を選ぶ）
- **起動直後の値は、試験の頭で取っておく**（あとの試験が盤を触ると変わる）
