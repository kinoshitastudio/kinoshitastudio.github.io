# 暈 KASA の試験

    bash kasa/_test/run.sh              # 通し試験（OK だけ並べば通過）
    node kasa/_test/move.mjs            # 「動き」がどれだけ絵を変えるかを実測する
    node kasa/_test/move2.mjs           # 光だけの動き・実寸の1コマ・揺れ を切り分けて測る
    python3 - <<'PY' ... PY             # ↓ same.mjs は先に HEAD を取り出しておく
    node kasa/_test/same.mjs            # 直す前（/tmp/kasa_head.html）と絵が同じか

⭐ **本体（index.html）は1行も触らない。** 複製の `</body>` の前に試験を差し込んで
headless Chrome で読む。`KASA` に出している入口（`paint` / `holesAt` / `ASEL` …）から測る。

⚠️ 見に行く本体は差し替えられる → `KASA_SRC=/tmp/kasa_head.html node kasa/_test/check.mjs`
（直す前と突き合わせるときに使う）

## 🔴 2026-08-25 に踏んだ型

- **Chrome が終わらずに試験が返らないことがある。** 結果は先に出ているので、
  `timeout` を付けて【途中まで出ている結果】を読む（`execFileSync` の timeout ＋ catch で stdout）
- **試験の並び順が状態を運ぶ。** 角の玉を「選んでから掴む」に変えたら、
  その先の試験（1本の指で絵がつかめる）まで落ちた＝**前の試験が作った状態**が変わったため。
  ⭐ 直したのは本体ではなく**その試験の手順**（先に絵を選ぶ）
- **起動直後の値は、試験の頭で取っておく**（あとの試験が盤を触ると変わる）

## ⭐ 動きの実測（`move.mjs`・2026-08-25）

木下＝「アニメーションがやはり動きがあまりない」。**幅を広げれば強くなる、ではなかった。**

| 設定 | 1/4周で変わった画素 | 明るさの平均のずれ |
|---|---|---|
| 既定（巡り.05 息.18） | 10.0% | 2.8 |
| 木下の設定（巡り.55 息.14） | 47.7% | **25.2** |
| いまの上限（巡り.8 息.8） | 48.0% | 31.4 |
| 巡りだけ 2.5（広げすぎ） | 23.9% | **5.6** ← 弱くなる |

🔴 **灯の巡りは 0.8 あたりが目安**。それ以上は灯が紙から出ていくので、かえって絵が変わらない。
⭐ 足りなかったのは幅ではなく**動くものの種類**＝光しか動いていなかった。
**穴の巡り**（黒い形そのものが回る）を足した。

## 🔴🔴 「穴を上げたら文字の動きが止まった」の切り分け（`move2.mjs`・2026-08-25）

木下＝「穴の回りをあげすぎると文字のうごきがとまった」。⭐ **測ったら止まっていなかった。**

| 穴の巡り | 光の動き（穴の黒を除いて数える） | 1コマ（実寸1150×719） |
|---|---|---|
| 0 | 48.1%（25.3） | 32ms |
| 0.44 | 48.1%（25.5） | 24ms |
| 0.80 | 48.2%（25.5） | 23ms |

＝**1%も変わっていない**。⭐ 本当の理由は【動いているのが光だけで、紙と文字そのものは
1画素も動いていない】こと。⭐⭐ そこで **揺れ**（刷り上がった絵ごとずらす）を足した。

| | 動いた画素 |
|---|---|
| 光も穴も揺れも 0 | **0**（完全に静止） |
| 揺れ .02 だけ | 24.1% |
| 揺れ .05 だけ | 40.8% |

⚠️ 場（紙の形）は作り直さない＝増える手間は canvas の写し1回ぶんだけ。
⚠️ 1周でぴったり戻る（sin/cos なので動画の継ぎ目も合う）。
