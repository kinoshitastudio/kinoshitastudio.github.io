Noa

Web Terminal
OSS / Claude Code

— 05

MINAMO

Chrome Extension
Tab Overview

JavaScriptChrome APICanvas

タブとウインドウが増えすぎて迷子になる——それを、ひとつの静かな水面に。

サイドパネルで全タブを俯瞰し、文脈ごとの「島」（Chrome タブグループ）に畳む。別ウインドウを今の窓へ集約し、閉じたタブは 7 日間アーカイブに残る。NOA から生まれた、タブの司令塔。

Chrome Web Store 申請待ち kinoshita.studio/minamo ↗ 詳しく見る →
