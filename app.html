— 01 Canvas Tool / Web App
— Product 01 / 2026
Canvas Tool · Infinite Whiteboard · Web App
Black Mirror
Board

"Where Designer's Intuition
meets Hacker's Command."

Now Live — bmboard.studio Chrome Extension — Black Mirror Browser ↗
— Overview

HTMLひとつ。依存ゼロ。ビルドなし。
外部ライブラリを持ち込まず、ブラウザだけで動く
インフィニットキャンバスツール。

描いた図形がターミナルに応え、
コマンドが「魔法」になる——
設計思想そのものをプロダクトに実装した。

bmboard.studio ↗ — Case Study / 体験翻訳の設計記録 設計記録を読む →

"ホワイトボードは思考の外部化装置だ。だがUIが思考の速度に追いつかないとき、道具は邪魔になる。
BMBoardは『速さ』と『深さ』を同時に解決しようとした最初のプロダクトだ。"

— 02 Music Platform / Web App
— Product 02 / 2026
Music Platform · Ambient Listening · Web App
Ateli.er

"中庭のような、静かな音楽空間。"

Now Live — atelistudio.com Chrome Extension — Ateli.er Player ↗ Chrome Extension — Ateli.er Clip ↗
— Overview

音楽は消費するものではなく、
空間として存在するものだ。

誰かのチャンネルに流れる音楽と、
静かに並走する。ただそれだけの体験を
Webアプリとして実装した。

atelistudio.com ↗ — Case Study / 体験翻訳の設計記録 設計記録を読む →

"Spotifyは音楽を『発見させる』プラットフォームだ。だが私が求めていたのは、誰かの音楽の横に静かに座れる場所だった。
中庭というメタファーは最初から決まっていた——そこは誰のものでもなく、誰でも入れる場所だ。"

— 03 Family App / Web App
— Product 03 / 2026
Family App · Context-Based Recommendation · Web App
KODOCO

"今日の文脈に、答える。"

Now Live — kodoco.jp
— Overview

「今日どこいく？」に、情報サイトは
答えられない。

天気、子どもの年齢、外出できる時間——
その文脈を読んで1スポットを提案する
子連れおでかけ案内アプリ。

kodoco.jp ↗ — Case Study / 体験翻訳の設計記録 設計記録を読む →

"既存のおでかけ情報サイトには、スポット一覧がある。でも私が疲れ果てた週末に必要なのは、一覧ではなく『答え』だった。
選択肢を減らすことが、体験設計においていかに重要か——KODOCOはその実証実験でもある。"
