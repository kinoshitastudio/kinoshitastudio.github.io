(^.^) HOW TO USE
STEP 01
スタートするGet Started
扉ページの 始める → をタップしてビルダーへ進みます。
前回の作業がある場合は ↺ 前回の下書きを復元 も表示されます。 Tap 始める → on the start screen to enter the builder.
If you have a saved draft, a ↺ Restore button will appear.
STEP 02
パーツを追加するAdd a Part
空のスロットをタップするとカタログが開きます。Hero・Nav・Section・CTA など種類ごとにパーツが並んでいます。 Tap an empty slot to open the catalog. Parts are grouped by type: Hero, Nav, Section, CTA and more.
STEP 03
順番を並び替えるReorder Parts
スロット下部の ↑ ↓ ボタンで順番を変更できます。
PCではドラッグ操作も、モバイルでは左端の ⠿ バーをドラッグ して並び替えられます。 Use the ↑ ↓ buttons to reorder parts.
On desktop you can drag. On mobile, drag the ⠿ handle on the left edge.
STEP 04
編集画面へ進むGo to Editor
パーツを並べたら画面下の 編集画面へ → をタップ。プレビューとコードが並んだ編集画面に移ります。 Once you've arranged your parts, tap 編集画面へ → at the bottom. You'll move to the editor with a live preview and code panel.
STEP 05
テキストを編集するEdit Text
✎ 編集 ボタンをONにすると、プレビュー内のテキストを直接タップして書き換えられます。選択してフォーマットバーの B / I / S / M / L / XL で書式変更も可能です。 Turn on ✎ 編集 to edit text directly in the preview. Select text and use the format bar B / I / S / M / L / XL to change formatting.
STEP 06
色・画像を変更するChange Colors & Images
要素をタップして選択し、フォーマットバーの 🎨 色・画像 ボタンを押します。コンテキストメニューから 文字色・背景色の変更 や 画像の差し替え・クロップ ができます。PCでは右クリックでも開けます。 Tap any element to select it, then press the 🎨 色・画像 button in the format bar. The context menu lets you change text color, background color, replace or crop images. On desktop, right-click also works.
STEP 07
言語を切り替えるSwitch Language
画面右上の EN JP ボタンでコンテンツの言語を切り替えられます。パーツに登録されている日本語・英語テキストが切り替わるので、多言語サイトの確認にも便利です。 Use the EN JP toggle in the top-right to switch the content language. Each part stores both JP and EN text, making it easy to build multilingual sites.
STEP 08
コードを書き出すExport Your Code
コピー でHTMLをクリップボードへ、ZIP で書き出し で index.html / css/style.css / img/ の構成でダウンロード。どのホスティングサービスにもそのまま置けるクリーンなコードです。

作業中は 下書き保存 で状態を保存でき、次回起動時に復元できます。 Use コピー to copy the HTML, or ZIP で書き出し to download index.html / css/style.css / img/. It's clean code you can host anywhere.
